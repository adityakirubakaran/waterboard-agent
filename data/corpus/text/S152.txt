GENERAL INFORMATION PACKAGE
The General Information Package, including its attachments, may be submitted in one of two ways.
Applicants are encouraged to utilize the Financial Assistance Application Submittal Tool (FAAST) to streamline the application submittal and review process, but if that creates a hardship, the package may instead be submitted by email.

[page 1] 1. Apply online via the FAAST: https://faast.waterboards.ca.gov To submit a DWSRF Application in FAAST, you must complete all the tabs in FAAST and attach (at a minimum) the General Information Package. (Note: Once the DWSRF Application has been uploaded, you must still complete the application by clicking on the “Submit” button.) Once the DWSRF Application is submitted in FAAST, a project manager will be assigned to help the applicant complete the application process. If a project is identified as eligible for the Expedited Drinking Water Grant (EDWG) Funding Program, which is an alternative funding pathway from the DWSRF Program, the assigned project manager will send a separate invitation to submit the application documents associated with the EDWG Funding Program in lieu of certain parts of the DWSRF Application.

[page 1] To submit additional documents for the same project, do not start a new application. Instead, click on the Submitted Applications link on the Main Menu and choose the project from the list of previously submitted applications. Open the Attachments tab, and then the Post-Submission sub-tab. Choose a document from the Attachment Category dropdown list and then select the file to upload. The project manager will receive an email notification letting them know you have submitted additional information for review.
If you need assistance, you can also contact the FAAST Help Desk, which is staffed Monday through Friday, 8:00 a.m. to 5:00 p.m., at 1-866-434-1083 or FAAST_ADMIN@waterboards.ca.gov.
2. To submit a DWSRF Application via email, please use the following email address:
DrinkingWaterSRF@waterboards.ca.gov
